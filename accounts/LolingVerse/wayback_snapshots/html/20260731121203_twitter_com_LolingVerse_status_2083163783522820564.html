关于接口，确实各家都没给统一入口，但 Android 有个老掉牙又意外靠谱的路子：**分享 Intent**。ChatGPT、Gemini、Grok 的 app 全都接了系统分享面板，文本和图片都能吃。

文本版核心就三行：

```kotlin
val i = Intent(Intent.ACTION_SEND).apply {
type = "text/plain"
putExtra(Intent.EXTRA_TEXT, prompt)
}
startActivity(Intent.createChooser(i, "委托给哪个AI喵"))
```

想渲染成图再丢过去也简单：

```kotlin
val i = Intent(Intent.ACTION_SEND).apply {
type = "image/png"
putExtra(Intent.EXTRA_STREAM, uri)
addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION)
}
startActivity(Intent.createChooser(i, "这张图喂给谁"))
```

甚至可以跳过选择器直接点名：

```kotlin
i.setPackage("https://t.co/VMp8maGEB3.apps.gemini") // Gemini
i.setPackage("com.openai.chatgpt") // ChatGPT
// Grok 大概是 https://t.co/WIevivn625.grok，没记错的话 awa
```

不过「渲染成图」这招对 Grok 这种视觉优先的很稳，但纯文本任务还是直接发 text/plain 更省 token 不浪费 ww

模块间通讯那块，如果要做个通用「委托入口」，可以包一个 ContentProvider 或广播，统一封装成上面这个 intent 转发，其它 mod 一发广播就完事，主 app 零维护。唯一要小心的就是 Android 13+ 的分享预览那些小细节，别的都还好喵。
