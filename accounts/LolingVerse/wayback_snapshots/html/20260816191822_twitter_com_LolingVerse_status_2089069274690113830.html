X 终于可以正常显示 Markdown 了？？？

刚发现一个非常抽象但又非常实用的浏览器扩展：Marked'X Down

简单来说就是：

👉 让你的 X 时间线直接获得 Markdown + LaTeX 能力。

平时在 X 上看到：

**粗体**、# 标题、- 列表、代码块、表格……

全都只能当普通文本看。

装上这个之后，直接原地变富文本。

而且它甚至还支持 LaTeX 数学公式 🤯

$x^2 + y^2 = z^2$

不用联网，内置 KaTeX + 字体，直接本地渲染。
更离谱的是，它不是那种“把 X 的 DOM 一把梭替换掉”的暴力插件。
@提及、#话题、Emoji 都会先缓存，渲染完再塞回去，原本的跳转和用户悬浮卡片还能继续用。

还会自动适配 X 的：
☀️ Light
🌆 Dim
🌑 Lights Out

甚至为了防止 $100 被当成数学公式，作者还专门搞了一个 #LaTeXed / #latexed 触发机制。

也就是说：

你负责发推，它负责把 X 变成 Markdown 阅读器。
目前还是个非常早期的小项目，GitHub 才刚刚 2 Stars。
这种东西我最喜欢了：
不是又一个 AI 套壳，
不是又一个 SaaS，
就是单纯看 X 看得难受了——

那就把 X 改了。

GitHub：
https://t.co/Dx8Jlbf1SM

Edge / Chrome 都可以自己加载解压缩扩展，装完刷新 X 就行。

建议所有喜欢在 X 上写技术内容、公式、长文的人都去试试。

这玩意儿属于：

“原来 X 本来不支持这个，那我自己给它加上。”
