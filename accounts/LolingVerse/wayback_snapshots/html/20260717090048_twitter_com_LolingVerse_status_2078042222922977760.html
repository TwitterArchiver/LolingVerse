**Tavily** 是目前 LLM / AI Agent 最受欢迎的商业搜索工具之一，专为 RAG 和 Agent 优化：

- 返回结构化、干净的结果（标题、URL、snippet、raw_content、可选 answer + 图片）
- 支持 `include_answer`、`search_depth`、`include_raw_content` 等参数
- 原生集成 LangChain、LlamaIndex、CrewAI 等框架
- 免费额度 1000 次/月，之后按量付费

它最大的优势是**开箱即用**，结果质量高、适合直接喂给 LLM。

### 开源 / 自托管搜索工具（重点对比）

以下是开源社区和自托管项目中实际使用较多的方案，特别是**能替代 Tavily** 的：

| 工具 | 开源协议 | Tavily 兼容性 | 核心特点 | 部署方式 | 适合场景 | 优缺点 |
|------|----------|---------------|----------|----------|----------|--------|
| **SearXNG** | AGPL | 无（需额外包装） | 元搜索引擎，聚合 70+ 引擎（Google、Bing、DuckDuckGo、Brave 等） | Docker 一键部署 | 本地 LLM、自托管 Agent | **最常用**的开源方案。隐私好、免费无限，但结果是原始 snippet，需要自己清洗 |
| **OrioSearch** | MIT | **极高**（drop-in 替换） | SearXNG + trafilatura 内容提取 + BYO LLM 生成 answer + rerank + 图片 | Docker Compose（含 SearXNG + Redis） | 想直接替换 Tavily 的自托管项目 | **目前最接近 Tavily 的开源方案**。支持 `include_answer`、SSE、tool schema |
| **UnSearch** | Apache 2.0 | 高（Tavily + Exa 兼容） | SearXNG + 神经检索 + 深度研究 Agent + 事实核查 | Cloudflare Workers / Docker | 需要语义搜索 + 深度研究的 Agent | 功能最丰富（类似 Exa + Tavily），自托管免费 |
| **ai-first-search** | MIT | 中 | DuckDuckGo 搜索 + 多 URL 清洗成 Markdown | FastAPI + Docker | 轻量级 search + read pipeline | 极简，专为 Agent 设计，返回干净 Markdown |
| **DuckDuckGo** (库) | - | 无 | `duckduckgo-search` Python 库 | 直接 pip install | 简单原型、早期 Agent | 最轻量，但不稳定（易被封） |

### 详细说明

**1. SearXNG（开源社区最主流）**
- 几乎所有本地 LLM 项目（Ollama + Open WebUI、AnythingLLM、自建 Agent）都在用。
- 支持 JSON 输出，LangChain / LlamaIndex 有社区集成。
- 很多项目再包一层 MCP Server（Model Context Protocol）让 Claude / Cursor / Open WebUI 直接调用。
- 缺点：只有 snippet，没有 Tavily 那种自动清洗后的 `raw_content` 和 `answer`。

**2. OrioSearch（最推荐的 Tavily 替代）**
- GitHub: `vkfolio/orio-search`
- **真正意义上的 drop-in 替换**：改一行 base_url 就能用现有 Tavily 代码。
- 自带内容提取（trafilatura，质量很高）+ 支持接 Ollama 等本地 LLM 生成带引用的 answer。
- 包含 rerank、Redis 缓存、SSE 流式等生产特性。
- 非常适合想**完全自托管 + 零费用**的团队。

**3. UnSearch**
- 同时兼容 Tavily 和 Exa 的 API。
- 有神经检索（semantic search）和深度研究 Agent 功能。
- 自托管或用他们的托管服务（免费额度比 Tavily 多 5 倍）。

**4. 其他轻量方案**
- `ai-first-search`：追求极简 “query → 干净 Markdown” 的可以直接用。
- 很多项目自己组合：**SearXNG（搜） + Jina Reader / Crawl4AI / trafilatura（取正文）**。

### 在开源 LLM 项目中的实际使用情况

- **LangChain / LangGraph**：官方推荐 Tavily，但社区大量使用 SearXNG + 自定义 Tool，或 OrioSearch。
- **LlamaIndex**：类似，支持多种 search 集成。
- **本地 / 自托管生态**（Ollama、Open WebUI、LM Studio 等）：**SearXNG 几乎是标配**。
- **早期 Agent 项目**（Auto-GPT 类）：多用 DuckDuckGo 库。
- **2025-2026 新项目**：越来越多直接用 **OrioSearch** 或 **UnSearch** 做 Tavily 替代。

### 推荐选择

| 你的需求 | 推荐方案 | 理由 |
|----------|----------|------|
| 快速原型、想最省事 | **Tavily** | 开箱即用，集成最好 |
| 本地/自托管、零成本、隐私优先 | **SearXNG**（基础）或 **OrioSearch**（进阶） | 完全免费可控 |
| 想要接近 Tavily 的体验 + 自托管 | **OrioSearch** | 最接近的 drop-in 方案 |
| 需要语义搜索 + 深度研究 | **UnSearch** | 功能最强 |
| 极简轻量 pipeline | **ai-first-search** | 返回干净 Markdown |

### 总结建议

- **想省事 + 生产稳定** → 先用 Tavily（免费额度够用）。
- **开源项目 / 自托管 / 长期零成本** → 优先 **OrioSearch**（最像 Tavily）或 **SearXNG + 内容提取层**。
- 很多团队的最终方案是 **混合使用**：SearXNG/OrioSearch 做主搜索 + Jina Reader / Firecrawl 做深度页面抓取。
